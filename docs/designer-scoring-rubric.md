# Designer Scoring Rubric

Each designer persona scores 0-10 per dimension, judging the site as a
professional reviewing a peer's shipped work. Anchors: 0-3 = would flag in a
crit as failing, 4-6 = competent but unremarkable, 7-8 = strong professional
work with specific craft visible, 9-10 = portfolio-grade; you would show this
as an example. A 9+ must cite the specific decision that earns it. Judge what
is actually rendered, not intent. IGNORE the image placeholders entirely:
score as if real photos/screenshots were in place, and do not deduct for a
gray placeholder box on any dimension.

## Dimensions

1. **Brand and identity system** — logo usage discipline, identity coherence
   across pages, does the bear/honey world feel owned rather than decorated.
2. **Typography** — scale, hierarchy, pairing; Thai typesetting craft
   (leading for mark stacking, tracking, line length, loanword breaks).
3. **Color system** — palette harmony, token discipline, contrast rigor,
   restraint (accent doing work vs decoration).
4. **Layout, spacing, rhythm** — grid discipline, section cadence,
   white space intentionality, alignment.
5. **Hierarchy and scannability** — can a skimmer get the story from
   headings/bolds; is the reading gravity right on every page.
6. **Component craft** — cards, chips, buttons, FAQ, browser frames:
   consistency, states, radius/shadow logic, icon set coherence.
7. **Motion** — do animations add life without noise; reduced-motion and
   no-JS behavior; anything that feels default or gratuitous.
8. **Responsive craft** — 320/375/834/1366 each look composed, not merely
   unbroken; logo swap, grid reflows, tap targets.
9. **Personality and memorability** — would you recognize this site
   tomorrow; does it avoid template/AI-default smell; is playfulness
   balanced against the trust job.
10. **Conversion design** — CTA placement and rhythm, friction to LINE,
    objection flow, does design serve the sale.

## Verdict block

- **Total** /100 and a letter grade (A/B/C/D).
- **Top 3 strengths** — specific, citable.
- **Top 5 fixes** — ranked, each with location, why, and effort (S/M/L).
- **"Would you ship this to a paying client?"** yes / with reservations / no.
- **The single change with the highest design ROI.**

## Ground rules

- Look at real renders (headless Chrome screenshots at your assigned widths)
  AND the source (src/) for system judgment. Cite file/selector or page +
  section for every criticism.
- Judge Thai typography as Thai — English-typography instincts about
  tracking/line-height do not transfer.
- No grading on a curve against "small freelancer site"; the bar is good
  professional work, period.
